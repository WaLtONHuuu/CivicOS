# NYC 311 入门样本

来源：纽约市官方 NYC Open Data，数据集 `erm2-nwe9`。

文件 `nyc311_2026-10_first10000.csv` 是 CSV 表格：一行一条服务请求。
查询 2026-10-01（含）至 2026-11-01（不含），按创建时间、请求编号升序取前 10,000 条。
这不是随机样本，也不是完整月份数据。适合认识字段、练习 pandas 和测试地图，不能用于统计整月总量、比较真实区域排名或训练每日需求预测。

| 字段 | 含义 |
| --- | --- |
| unique_key | 请求唯一编号，建议按文本读取 |
| created_date | 创建时间 |
| closed_date | 关闭时间，可能为空 |
| complaint_type | 问题类型 |
| status | 状态 |
| borough | 行政区 |
| latitude | 纬度 |
| longitude | 经度 |

缺失坐标的记录仍保留，绘制地图时过滤。关闭时间为空不代表处理时长为零。
源时间字段按原样保留，按日统计前应确认纽约本地时间口径。
状态和关闭时间是下载时的记录值，不代表历史时点的状态。
查询地址、下载时间、实际时间范围和检查结果见同目录 metadata JSON。
